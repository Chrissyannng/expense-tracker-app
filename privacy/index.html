Privacy Policy

Last updated: October 2026

Scope

This policy covers Expense Tracker, a single-user personal finance application operated by its owner for their own use.

Data accessed

With the owner's explicit authorization, the application uses the Gmail API with the read-only scope (gmail.readonly). It reads only messages from the owner's banks that contain account or credit card statements. It does not send, modify, or delete email.

How data is used

Statement attachments are downloaded to the owner's computer and used solely to reconcile the owner's personal financial records.

Storage and sharing

All data stays on the owner's local machine. No data is sold, shared with third parties, or used for advertising. Google user data is not transferred to any external server.

Limited Use

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
